# Indiana State University – 3D Campus Model

Work in progress. 3D reconstruction of the Indiana State University main campus (Terre Haute, Indiana):
buildings with construction drawings are modelled in detail; the rest are massed from OpenStreetMap
footprints, satellite imagery and street-level photos.

Layout (planned):

- `tools/` – data collection and generation scripts
- `data/` – collected footprints, imagery index, building inventory (large binaries live in GitHub Releases)
- `viewer/` – Three.js web viewer
- `model/` – exported GLB files
